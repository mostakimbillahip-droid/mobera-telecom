# Mobera Telecom — Starter Website

এটি Mobera Telecom-এর একটি responsive frontend starter/demo।

পরবর্তী ধাপে যোগ করা যাবে:
1. Login/Registration + OTP
2. Database
3. User wallet/balance
4. Real mobile recharge API
5. Payment gateway
6. Transaction history
7. Admin panel
8. SMS/notification
9. Domain + hosting deployment

নোট: বর্তমান Recharge button শুধু demo; কোনো আসল টাকা বা recharge transaction করে না।
